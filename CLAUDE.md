# Страница поездки в Нью-Йорк — как её править

Этот репозиторий целиком собирает одну страницу: план поездки Георгия и Насти
в Нью-Йорк, 7–11 октября 2026. Опубликована на
**https://georgelit.github.io/nyc-trip/**

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Сама страница. Весь текст и стили внутри, один файл без зависимостей |
| `publish.sh` | Публикация. Единственный способ выложить изменения |
| `tools/publish.py` | Внутренности публикации: версии, снимки, история |
| `v/` | Замороженные версии и страница истории. **Руками не трогать**, папку собирает скрипт |
| `v/versions.tsv` | Журнал версий: номер, время, автор, комментарий |

## Как вносить правки

1. **Сначала подтяни чужое:** `git pull --rebase`
2. Правь `index.html`
3. Публикуй: `./publish.sh "коротко что изменил"`

Скрипт сам увеличит номер версии, проставит штамп в шапку и подвал, заморозит копию
в `v/vN.html`, перестроит страницу истории и отправит всё на GitHub. Живая страница
обновляется примерно за две минуты.

**Не редактируй руками** штамп версии (`<span class="ver">`) и ссылку на версию
в подвале: их проставляет скрипт, ручная правка собьёт нумерацию.

**Не коммить и не пушь напрямую.** Только `./publish.sh`, иначе версия не запишется.

## 🔴 Репозиторий публичный

Страницу видит любой, у кого есть ссылка. На неё **не выкладываем**:

- домашний адрес Якоба (на странице только «Journal Square»)
- номер брони на рейс, номера мест, паспортные данные
- телефоны и почту Якоба и его девушки

Всё это живёт в заметке vault `30-Life/Нью-Йорк 07-11.10.md`, она локальная.

## Правила по содержанию

- **Не выдумывай факты.** Часы работы, цены, времена в пути, расписания: только
  проверенные. Если не знаешь, так и напиши на странице или спроси. По этой странице
  будут реально ходить: ошибка в часах работы означает закрытую дверь.
- Весь текст **по-русски**, без тире в качестве разделителя мысли: вместо него
  двоеточие, запятая или отдельное предложение.
- Цены в долларах, потому что тратим на месте. Евро только там, где сравниваем с Германией.
- Времена в шапке дня и в таймлайне должны сходиться между собой.

## Правила по вёрстке

- Страницу смотрят **в основном с iPhone**. После правки проверь ширину 375 пикселей:
  страница не должна прокручиваться вбок, таблицы не уезжают за экран.
- Работают обе темы, светлая и тёмная. Цвета только из переменных (`var(--ink)`,
  `var(--card)` и так далее), новые хардкодные цвета не добавлять.
- Никаких внешних ссылок на шрифты, скрипты и картинки: страница обязана работать
  одним файлом.
- Пять цветов дней закреплены в `--d1` до `--d5`, взяты с ньюйоркских линий метро.

## Если публикация ругается

- `could not read Username` — `gh auth login`, затем `gh auth setup-git`
- конфликт при `git pull --rebase` — разреши в `index.html`, `git rebase --continue`,
  потом снова `./publish.sh`
- `не нашёл штамп версии` — кто-то удалил `<span class="ver">` из шапки или ссылку
  из подвала. Верни их на место
